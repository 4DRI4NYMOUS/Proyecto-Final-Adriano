en esta web se mostrara lo aprendido durante las clases de "Introduccion al Desarrolo Web"
comenzemos explicando los tres lenguajes principales que se utilizan en el desarrollo web:

HTML:

(HyperText Markup Language) es el esqueleto de una pagina web. En el se construye la estructura principal del sitio, definiendo que elementos existen y como se organizan. Permite crear titulos, parrafos, listas, tablas, imagenes, enlaces, formularios y otros componentes que conforman el contenido.En esencia, HTML establece la base sobre la que trabajaran CSS y JavaScript.

CSS:

(Cascading Style Sheets) es el lenguaje encargado de la apariencia visual de la pagina web. A partir de la estructura creada con HTML, permite definir colores, tipografias, tamaños, margenes, posiciones, animaciones y el diseño adaptable a distintos dispositivos. Su función es transformar una estructura simple en una interfaz atractiva, ordenada y facil de leer.

JS:

JavaScript es el lenguaje de programación que aporta comportamiento e interactividad a la pagina web. Permite responder a las acciones del usuario, modificar el contenido sin necesidad de recargar la pagina, validar formularios, crear animaciones, actualizar datos en tiempo real y controlar la logica de funcionamiento del sitio. En conjunto con HTML y CSS, convierte una pagina estatica en una aplicacion web dinámica.

Habiendo explicado de forma simple los 3 lenguajes, continuemos con ejemplos de su aplicación, mostrando como se ve una pagina antes y despues de usar HTML solo, o junto a CSS y JS.
